# Optional real piano note samples

The app can now generate warm acoustic-style piano tones in code, so these files are optional.

For the best production sound, add real recorded piano samples with these names:

- c.mp3
- c_sharp.mp3
- d.mp3
- d_sharp.mp3
- e.mp3
- f.mp3
- f_sharp.mp3
- g.mp3
- g_sharp.mp3
- a.mp3
- a_sharp.mp3
- b.mp3
- high_c.mp3

If a file is missing, the app safely falls back to generated piano audio.

Recommended sample style:
- short clean acoustic piano note
- no background noise
- 44.1 kHz or 48 kHz
- mono or stereo
- around 1-2 seconds long
- gentle velocity suitable for children
